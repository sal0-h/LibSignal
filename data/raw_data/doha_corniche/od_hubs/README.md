# Hub-centric OD demand (Doha Corniche)

Synthetic demand layer (1800 s episodes) on the real OSM network.

- `taz.xml` — fringe (N/E/S/W), internal 2×2, hub `hub_corniche` (Al Corniche Street)
- `demand_set/` — generated by `extras/gen_od_hub_demand_doha.py`

Not calibrated Doha traffic. Routing: SUMO `od2trips` + `duarouter`. See `docs/DOHA_NETWORK.md` and `docs/OD_HUB_DEMAND.md`.
